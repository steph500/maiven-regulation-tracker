# Single-page UI specification

Use the provided botanical Regulation Tracker image for visual direction: cream background, navy editorial headings, forest-green actions, spacious search panel and dense white document cards. Decorations stay local and decorative.

One application page: header and real indexed count; Track EPA Rules hero; Keyword/Semantic/Hybrid segmented control; large labeled search input; one compact date-range popover; visible newest-first baseline ordering; Search and Reset; results and Load 20 more.

Cards show actual title, abstract, publication date, optional effective date, document_number, available source agency and original Federal Register link. Never invent topic tags or other metadata from the reference. Actual historical snapshots appear in a dialog.

Enter submits. New submitted criteria reset pagination; Load More appends and guards duplicate pending requests. Reset returns to unfiltered first 20. Include accessible labels/focus, mobile layout, readable type, loading, empty and error states. Semantic results may show a match label without decimal scores.
